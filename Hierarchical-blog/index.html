01 — INTRODUCTION

How does it work?

Hierarchical Clustering groups similar data points into a hierarchy. The agglomerative approach starts with individual points and repeatedly merges the closest groups.

01
📏

Measure distance

Calculate how far the data points or clusters are from one another.

02

Merge groups

Join the two closest clusters according to the selected linkage method.

03

Record each merge in a tree-like diagram called a dendrogram.

04

Cut the hierarchy at a selected level to obtain the desired groups.

03 — UNDERSTANDING

Two ways to build a hierarchy

The algorithm can build the hierarchy from the bottom up or the top down.

MOST COMMON APPROACH

Agglomerative Clustering

Bottom-up approach: each point starts as its own cluster, and the closest clusters are merged repeatedly.

●●→●●→●●●
ALTERNATIVE APPROACH

Divisive Clustering

Top-down approach: all points begin in one cluster, which is repeatedly split into smaller groups.

●●●●→●●●●
🌳

What is a dendrogram?

A dendrogram is a tree diagram showing the order in which clusters merge. The height of a merge represents the distance or dissimilarity at which two groups are joined.

04 — FORMULA

Average linkage distance

Different linkage methods define the distance between two clusters differently.

AVERAGE LINKAGE
d(A, B) = 1 |A| × |B| ∑x ∈ A ∑y ∈ B d(x, y)

Where:

  • A and B are two clusters.
  • d(x, y) is the distance between two data points.
  • |A| and |B| are the number of points in each cluster.
SingleMinimum pairwise distance
CompleteMaximum pairwise distance
AverageMean pairwise distance
WardMinimizes increase in within-cluster variance

07 — PYTHON IMPLEMENTATION

Write your first program

This example uses SciPy to calculate a linkage matrix and draw a dendrogram.

hierarchical_clustering.py 
import numpy as np
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster

# Sample data: eight points in two dimensions
X = np.array([
    [1, 2], [1.5, 1.8], [2, 1],
    [5, 8], [6, 8], [5.5, 7],
    [8, 2], [9, 3]
])

# Build the hierarchical tree
Z = linkage(X, method="ward")

# Form three clusters from the hierarchy
labels = fcluster(Z, t=3, criterion="maxclust")

print("Cluster labels:")
print(labels)
print("Number of clusters:", len(np.unique(labels)))

# Display the dendrogram
plt.figure(figsize=(9, 5))
dendrogram(Z, labels=[f"P{i+1}" for i in range(len(X))])
plt.title("Hierarchical Clustering Dendrogram")
plt.xlabel("Data Points")
plt.ylabel("Merge Distance")
plt.tight_layout()
plt.show()

# Plot the resulting clusters
plt.figure(figsize=(7, 5))
for label in np.unique(labels):
    points = X[labels == label]
    plt.scatter(points[:, 0], points[:, 1], label=f"Cluster {label}")

plt.title("Hierarchical Clustering Groups")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.legend()
plt.tight_layout()
plt.show()

09 — READING THE GRAPH

How to interpret a dendrogram

Look at the vertical merge heights to understand which groups are similar and how far apart they are.

Low merge height

Groups are joined at a small distance, indicating greater similarity under the selected metric and linkage.

High merge height

Groups are joined at a larger distance, suggesting they are less similar.

Horizontal cut

A horizontal cut through the tree determines the resulting clusters. Cutting at different heights can give different numbers of groups.

10 — QUICK REVISION

Advantages and limitations

✓ Advantages

• Shows nested relationships between groups.

• A dendrogram helps explore different cluster counts.

• Supports multiple linkage methods.

• Useful for exploratory data analysis.

! Limitations

• Can be computationally expensive on large datasets.

• Sensitive to distance measures and linkage choices.

• Early merges in agglomerative clustering are not normally undone.

• Outliers can affect the resulting hierarchy.

YOUR TAKEAWAY

See the bigger picture in your data.

Hierarchical Clustering is an unsupervised learning method that creates a hierarchy of groups. With linkage methods and dendrograms, we can explore similarities and choose meaningful clusters.
