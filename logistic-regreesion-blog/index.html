01 / INTRODUCTION

What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm mainly used to predict categories.

🎯

Classification

Predicts a class such as Pass or Fail, Yes or No, and Approved or Denied.

📊

Probability

Estimates the probability that an observation belongs to a particular class.

🧠

Supervised Learning

Learns from labelled examples where the correct category is already known.

Remember: Linear Regression predicts a numerical value, while Logistic Regression is commonly used to predict a category.

04 / UNDERSTANDING THE CONCEPT

Why the sigmoid function?

A linear score can have any value. The sigmoid function converts it into a value between 0 and 1.

Understanding probability

A probability closer to 1 indicates stronger support for the positive class. A probability closer to 0 indicates stronger support for the negative class.

  • Probability is between 0 and 1.
  • 0.5 is a common classification threshold.
  • The threshold can change depending on the application.
  • The predicted probability is not a guarantee.

05 / MATHEMATICAL FORMULA

The Logistic Regression formula

The sigmoid function transforms a linear score into a probability.

SIGMOID FUNCTION
P(Y = 1 | X) = 11 + e−z

where z = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

P(Y = 1 | X)Probability of the positive class
eEuler's number, approximately 2.718
b₀Intercept or bias
b₁, b₂, ...Learned model coefficients
x₁, x₂, ...Input features
Decision rule: With a threshold of 0.5, predict class 1 when the probability is at least 0.5; otherwise predict class 0. Other thresholds may be appropriate.

07 / PYTHON IMPLEMENTATION

Build your first model

Use Scikit-learn to train a Logistic Regression model on a small student dataset.

logistic_regression.py
from sklearn.linear_model import LogisticRegression

# Study hours and exam results
X = [[1], [2], [3], [4], [5], [6]]
y = [0, 0, 0, 1, 1, 1]  # 0 = Fail, 1 = Pass

# Create and train the model
model = LogisticRegression()
model.fit(X, y)

# Predict the result for a student studying 4 hours
hours = [[4]]
prediction = model.predict(hours)[0]
probability = model.predict_proba(hours)[0][1]

print("Predicted class:", prediction)
print("Predicted result:",
      "Pass" if prediction == 1 else "Fail")
print("Probability of passing:",
      round(probability, 3))

08 / MODEL EVALUATION

How do we evaluate it?

Use test data and appropriate metrics to check how well the classifier performs.

🎯

Accuracy

Proportion of all predictions that are correct.

Correct predictions / Total
🔎

Precision

Among positive predictions, the proportion that are correct.

TP / (TP + FP)
📈

Recall

Among actual positive cases, the proportion correctly identified.

TP / (TP + FN)
