01 — THE BASICS

What is Linear Regression?

Let's understand the concept from the beginning.

Linear Regression is a supervised machine learning algorithm used to predict numerical values by learning the relationship between variables.

It finds a best-fit straight line through data points. This line helps us estimate an output for a new input.

Simple example: Predicting a student's marks using the number of hours they study.

How does it work?

01

Collect Data

Collect information such as study hours and student marks.

02

Train the Model

The algorithm learns the relationship between input and output.

03

Find the Line

It finds a line that minimizes the squared prediction errors.

04

Make Predictions

Use the learned line to estimate a new numerical value.

03 — MATHEMATICS

Understand the Formula

A simple equation is the foundation of Linear Regression.

ŷ = b₀ + b₁x

ŷ — Predicted output

x — Input variable

b₀ — Intercept

b₁ — Slope of the line

Types of Linear Regression

Simple Linear Regression: Uses one input variable to predict an output.

Multiple Linear Regression: Uses two or more input variables to predict an output.

05 — PRACTICAL LEARNING

Implement it using Python

Train a model and predict marks for six study hours.

Python · linear_regression.py
import numpy as np
from sklearn.linear_model import LinearRegression

# Input: Study hours
X = np.array([1, 2, 3, 4, 5]).reshape(-1, 1)

# Output: Student marks
y = np.array([30, 40, 50, 60, 70])

# Create and train the model
model = LinearRegression()
model.fit(X, y)

# Predict marks for 6 study hours
prediction = model.predict([[6]])

print("Slope:", model.coef_[0])
print("Intercept:", model.intercept_)
print("Predicted marks:", prediction[0])

How to run the code

1. Install Python on your computer.

2. Open your terminal and run:

pip install numpy scikit-learn

3. Save the program as linear_regression.py.

4. Run python linear_regression.py.
