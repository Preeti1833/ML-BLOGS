01 — INTRODUCTION

What is PCA?

Principal Component Analysis is a statistical technique used to reduce the number of variables in a dataset. It creates new features called principal components, ordered by how much variance they explain.

Think of it this way: Imagine describing a photo with thousands of pixel values. PCA helps represent the main patterns using fewer numbers, making the data easier to analyze.

02 — HOW IT WORKS

The PCA Workflow

PCA finds directions in which the data varies the most, then projects the data onto the strongest directions.

1 Standardize Put features on comparable scales when needed.
2 Find Variance Calculate covariance or use SVD.
3 Rank Components Keep directions with the most variance.
4 Transform Project data into fewer dimensions.
03 — THE MATH

PCA Formula

Z = XW

X = centered or standardized data matrix
W = selected principal-component directions
Z = transformed data in fewer dimensions

Explained Variance Ratio
It represents the proportion of the dataset's variance captured by a principal component. Adding the ratios of retained components tells us how much variance is preserved.
04 — PYTHON IMPLEMENTATION

PCA Using Scikit-learn

import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Load a dataset with 4 numeric features
iris = load_iris()
X = iris.data

# Standardize the features
X_scaled = StandardScaler().fit_transform(X)

# Reduce 4 features to 2 components
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print("Original shape:", X.shape)
print("Reduced shape:", X_pca.shape)
print("Variance explained:",
      pca.explained_variance_ratio_.round(3))
print("Total variance kept:",
      round(pca.explained_variance_ratio_.sum() * 100, 2), "%")

# Plot the transformed data
plt.scatter(
    X_pca[:, 0],
    X_pca[:, 1],
    c=iris.target,
    cmap="viridis"
)

plt.xlabel("Principal Component 1")
plt.ylabel("Principal Component 2")
plt.title("Iris Dataset After PCA")
plt.show()

Tip: Standardization is important when features have different units or scales. PCA centers the data, but does not automatically scale every feature.

09 — ADVANTAGES & LIMITATIONS

What to Remember

✓ Advantages

  • Reduces dimensionality.
  • Can speed up later analysis.
  • Helps visualize complex datasets.
  • Can reduce some noise.

! Limitations

  • Some information may be lost.
  • Components can be hard to interpret.
  • Captures linear patterns.
  • Results can depend on scaling.
10 — CONCLUSION
✦

Fewer Dimensions. More Insight.

PCA is a useful technique for simplifying high-dimensional data. By retaining components that explain much of the variance, it can make datasets easier to visualize and analyze.
