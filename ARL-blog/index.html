01 — INTRODUCTION

What is Association Rule Learning?

Association Rule Learning is an unsupervised machine learning technique used to discover relationships between items in large datasets. It identifies which items frequently occur together.

🎯
Simple idea

If customers often buy bread and butter together, a store can discover this pattern and recommend related products.

🔍

Discover

Find patterns hidden in transaction data.

🔗

Connect

Identify relationships between different items.

📈

Improve

Use discovered patterns to support decisions.

04 — UNDERSTANDING

Three Important Measures

These measures help us evaluate the strength and usefulness of an association rule.

S

Support

How frequently the items in a rule appear together in all transactions.

Higher support = more common combination
C

Confidence

How often the consequent appears when the antecedent appears.

Higher confidence = more reliable prediction
L

Lift

How strongly the items are associated compared with independent occurrence.

Lift above 1 suggests positive association
Remember: A high confidence value alone does not prove a strong relationship. Lift helps compare the rule against the item's overall frequency.
05 — FORMULAS

Mathematical Formulas

Let A and B represent two itemsets, and N be the total number of transactions.

SUPPORT
Support(A → B) = Count(A ∪ B) / N

Fraction of transactions containing both A and B.

CONFIDENCE
Confidence(A → B) = Support(A ∪ B) / Support(A)

Probability of B occurring when A occurs, estimated from the data.

LIFT
Lift(A → B) = Confidence(A → B) / Support(B)

Compares the rule's confidence with B's overall support.

07 — WORKED EXAMPLE

Calculate a Rule Step by Step

Consider the rule Bread → Butter using the same transactions.

STEP 1

Support

Both Bread and Butter occur together in T2 and T3.

2 / 5 = 40%
STEP 2

Confidence

Bread occurs in 4 transactions; both items occur in 2.

2 / 4 = 50%
STEP 3

Lift

Butter occurs in 3 out of 5 transactions.

0.50 / 0.60 = 0.83
Conclusion: In this small example, Bread and Butter occur together in 40% of transactions. Their lift is below 1, so the data does not indicate a positive association.
08 — PYTHON CODE

Implement Association Rules in Python

This beginner-friendly example uses the mlxtend library and the Apriori algorithm.

association_rules.py 
import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

# Sample shopping transactions
transactions = [
    ["Bread", "Milk"],
    ["Bread", "Butter", "Milk"],
    ["Bread", "Butter"],
    ["Milk", "Butter"],
    ["Bread", "Milk"]
]

# Convert transactions into a Boolean table
encoder = TransactionEncoder()
encoded = encoder.fit(transactions).transform(transactions)
df = pd.DataFrame(encoded, columns=encoder.columns_)

print("Transaction Data:")
print(df.astype(int))

# Find frequent itemsets
frequent_items = apriori(
    df, min_support=0.2, use_colnames=True
)

print("\\nFrequent Itemsets:")
print(frequent_items)

# Generate association rules
rules = association_rules(
    frequent_items, metric="confidence", min_threshold=0.5
)

print("\\nAssociation Rules:")
print(rules[["antecedents", "consequents",
             "support", "confidence", "lift"]].round(2))

11 — CONCLUSION

Key Takeaways

Association Rule Learning discovers useful relationships between items by analysing transaction data. Algorithms such as Apriori help find frequent itemsets and generate rules that can support recommendations, product placement and business decisions.

✓ Support measures frequency.
✓ Confidence measures conditional frequency.
✓ Lift compares a rule against independent occurrence.
✓ Rules describe associations, not necessarily causation.
