01 — THE BASICS

How is K-Means used?

K-Means is an unsupervised machine learning algorithm that divides data into K groups based on similarity. Each group is called a cluster, and its center is called a centroid.

🎯

Find Similar Data

Groups data points that have similar features or values.

📍

Find Cluster Centers

Calculates a centroid representing the center of each group.

🔄

Improve Groups

Repeatedly assigns points and updates centroids until the clusters stabilize or a stopping condition is reached.

03 — UNDERSTANDING THE ALGORITHM

How does K-Means work?

Imagine sorting a mixed collection of objects into groups. K-Means follows these four main steps.

01

Choose K

Decide how many clusters you want to create.

02

Initialize Centroids

Select initial centers for the clusters.

03

Assign and Update

Assign each point to the nearest center, then recalculate each center using the mean of its assigned points.

04

Repeat

Repeat assignment and updating until the centers stabilize or the stopping condition is reached.

04 — THE MATHEMATICS

K-Means formula

The algorithm minimizes the total squared distance between each data point and its assigned centroid.

J = ∑i=1N ||xi − μc(i)||²

Where:

  • xᵢ = a data point
  • μc(i) = centroid of the assigned cluster
  • N = total number of data points
  • J = total within-cluster squared distance

07 — HANDS-ON PYTHON

Implement K-Means in Python

This example creates sample data, forms three clusters, and plots the points with their centroids.

kmeans_example.py 
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

# Create sample data with three groups
X, y = make_blobs(
    n_samples=150,
    centers=3,
    cluster_std=0.8,
    random_state=42
)

# Create and train the K-Means model
model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)
model.fit(X)

# Get cluster labels and centroids
labels = model.labels_
centers = model.cluster_centers_

print("First 10 cluster labels:")
print(labels[:10])
print("Cluster centers:")
print(centers)
print("Inertia:", round(model.inertia_, 2))

# Plot the clusters
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap="viridis")
plt.scatter(
    centers[:, 0], centers[:, 1],
    marker="X", s=250, c="red", label="Centroids"
)
plt.title("K-Means Clustering")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.legend()
plt.show()

09 — VISUAL INSIGHT

Understanding the graph

Each dot represents a data point. Dots assigned to the same cluster share a color, and each X represents a centroid.

● ● ● ×

Closer points, similar group

K-Means assigns points to their nearest centroid using distance. The clusters may change as centroids move during training.

10 — QUICK REVISION

Advantages and limitations

✓ Advantages

Simple to understand and implement.

Efficient for many datasets.

Useful for discovering groups in unlabeled data.

! Limitations

You must choose K in advance.

Results can depend on initial centroids.

Outliers and irregularly shaped groups can cause problems.

YOUR TAKEAWAY

Turn data into meaningful groups.

K-Means is a useful unsupervised learning algorithm that groups similar data points by repeatedly assigning them to centroids and updating those centers.
