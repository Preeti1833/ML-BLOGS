01 / INTRODUCTION

What is a Decision Tree?

A Decision Tree is a supervised Machine Learning algorithm that learns rules from data to predict a class or a numerical value.

🌱

Simple to Understand

It works like a flowchart and makes predictions by following a series of questions.

🧠

Learns from Data

It identifies useful features and splitting rules from examples in the training data.

🎯

Two Main Types

Classification predicts categories; regression predicts numerical values.

02 / UNDERSTANDING

Meet the parts of a tree

Every part has a job. Select a component to learn what it does.

◎
TREE COMPONENT

Root Node

The root node is the starting point of a decision tree. It asks the first question and splits the data into smaller groups.

Example

“Did the student study for at least 3 hours?”

03 / HOW IT IS USED

From data to prediction

The algorithm learns rules during training, then follows those rules to make predictions.

▤STEP 01

Collect Data

Gather examples with features and known outcomes.

⌘STEP 02

Choose Splits

Find questions that separate the data into useful groups.

⑂STEP 03

Build the Tree

Repeat splitting until a stopping condition is reached.

✓STEP 04

Predict

Follow the branches to reach a final prediction.

06 / FORMULAS

How does a tree choose a split?

For classification, common split criteria include Gini impurity and Entropy.

METHOD 01

Gini Impurity

Gini = 1 − Σ pᵢ²

Measures how often a randomly selected sample would be incorrectly classified if labeled according to the class proportions in a node.

Lower is better0 = pure node
METHOD 02

Entropy

H = −Σ pᵢ log₂(pᵢ)

Measures uncertainty in a node. Information gain measures the reduction in entropy after a split.

Lower uncertainty0 = pure node
What is pᵢ? It is the proportion of samples belonging to class i in that node. The algorithm compares candidate splits and selects one according to its chosen criterion.
07 / HANDS-ON PYTHON

Build a Decision Tree in Python

This example trains a classifier to predict a simplified student outcome using study hours and attendance.

decision_tree.py
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeClassifier, plot_tree

# Features: [study hours, attendance percentage]
X = [
    [1, 50], [1, 70], [1, 80],
    [2, 60], [2, 80], [2, 90],
    [3, 50], [3, 60], [3, 80],
    [4, 50], [4, 70], [4, 80]
]

# 0 = Needs improvement, 1 = Pass
y = [
    0, 0, 1,
    0, 1, 1,
    1, 1, 1,
    1, 1, 1
]

model = DecisionTreeClassifier(
    criterion="gini",
    max_depth=3,
    random_state=42
)
model.fit(X, y)

student = [[2, 80]]
prediction = model.predict(student)[0]

labels = {0: "Needs improvement", 1: "Pass"}
print("Predicted result:", labels[prediction])
print("Training accuracy:", round(model.score(X, y), 2))

# Draw the learned decision tree
plt.figure(figsize=(12, 6))
plot_tree(
    model,
    feature_names=["Study hours", "Attendance"],
    class_names=["Needs improvement", "Pass"],
    filled=True,
    rounded=True
)
plt.title("Decision Tree: Student Outcome")
plt.tight_layout()
plt.show()
PYTHON 3Requires scikit-learn + matplotlib

08 / QUICK REVIEW

Advantages and limitations

✓ Advantages

  • Easy to understand and visualize
  • Can model nonlinear relationships
  • Works with classification and regression
  • Usually needs little feature scaling

! Limitations

  • Can overfit if the tree becomes too complex
  • Small data changes may change the tree
  • A single tree may be less accurate than an ensemble
  • Biased data can lead to unfair predictions
